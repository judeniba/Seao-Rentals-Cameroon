## Common Workflows

### Book Equipment
1. Browse categories or search
2. Click equipment card
3. View details & reviews
4. Click "Request Rental" or WhatsApp button
5. Fill inquiry form
6. Receive confirmation

### Track Rental
1. Click Rental History (header)
2. View active rentals
3. Click "Track Delivery" for status
4. Check notifications for updates

### Apply Discount
1. Click Menu → Promotions
2. Copy promo code
3. Use during checkout
4. See instant savings

### Earn Loyalty Points
1. Click Menu → Loyalty Program
2. View current tier & points
3. Complete rentals to earn points
4. Unlock tier benefits
5. Redeem rewards

### Get Support
1. Click Quick Actions (+)
2. Select "Service Request"
3. Fill issue form
4. Track request status
5. Receive technician updates
