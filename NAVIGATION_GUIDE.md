# SEAO-RENTALS Navigation Guide

## Overview
The navigation system has been completely reorganized for better usability and cleaner design. This guide explains how to access all platform features.

## Navigation Components

### 1. Main Header (Always Visible)
Located at the top of every page with essential controls:

- **Info Button (ℹ️)** - Opens Feature Overview Dashboard to discover all capabilities
- **Notifications Bell** - Manage email, SMS, and WhatsApp notification preferences
- **Rental History** - View all your past and current rental requests
- **Account Menu** - Login, profile management, and authentication
- **Language Toggle** - Switch between French and English
- **Menu Button (≡)** - Opens organized navigation menu
- **WhatsApp** - Direct contact via WhatsApp
- **Email/Phone** - Contact information (visible on larger screens)

### 2. Navigation Menu (Side Sheet)
Click the **Menu button (≡)** to access all features organized by category:

#### Rewards & Savings
- **Loyalty Program** 🏆 - Earn points and unlock tier benefits (Bronze → Platinum)
- **Bulk Discounts** - Save up to 15% on multiple equipment rentals
- **Seasonal Offers** 🎉 - Limited-time holiday and seasonal promotions
- **Promo Codes** - Apply discount codes at checkout
- **Refer & Earn** - Get 50 points for every successful referral

#### Rental Services
- **Equipment Packages** - Pre-configured bundles for construction, events, industrial
- **Compare Equipment** - Side-by-side comparison of up to 3 items
- **Insurance Plans** - 4 coverage tiers for damage, theft, weather protection
- **Service Request** - Request repairs, maintenance, or technical support

#### Tracking & Billing
- **Delivery Tracking** - Real-time tracking with driver details and ETA
- **Invoices** - Download and manage rental invoices
- **Payment History** - Track Orange Money and MTN Momo payments

#### Admin Tools (Owner Only)
- **Admin Dashboard** - Rental, customer, and equipment management
- **Backend Portal** - Comprehensive backend management system
- **Analytics** - Equipment utilization, revenue trends, demand patterns
- **Communications** - Multi-channel messaging hub (Email/SMS/WhatsApp)
- **SMS History** - View SMS notification delivery history
- **Maintenance** - Equipment maintenance scheduling and tracking

### 3. Quick Actions Menu (Floating Button)
Bottom-right corner **+ button** provides instant access to most-used features:

- **WhatsApp Us** (Green) - Direct WhatsApp contact
- **Service Request** (Blue) - Report equipment issues
- **View Packages** (Purple) - Browse equipment bundles
- **Insurance** (Indigo) - Protection plan selection
- **Compare** (Teal) - Equipment comparison tool
- **Track Delivery** (Orange) - Delivery status tracking
- **Invoices** (Amber) - Invoice management
- **Loyalty** (Yellow) - Rewards program dashboard
- **Promotions** (Pink) - View current offers

### 4. Feature Overview Dashboard
Click the **Info button (ℹ️)** in header to explore all features:

**4 Tabs Available:**
- **All (27)** - Complete feature list
- **Customer (12)** - Core rental experience features
- **Tools (6)** - Utility and support features
- **Admin (3)** - Management features (owner only)

Each feature card includes:
- Icon with color coding
- Feature name and description
- Badges for special features
- Click to learn more

## Usage Tips

### For New Users
1. Click **Info button** to see Feature Overview Dashboard
2. Browse features by category to understand what's available
3. Use **Quick Actions Menu** for common tasks
4. Access **Menu** for organized feature navigation

### For Regular Users
1. Use **Quick Actions Menu** for frequently-used features
2. Pin favorites in your mental map via **Navigation Menu**
3. Check **Notifications** for rental status updates
4. Monitor **Loyalty Dashboard** to track rewards progress

### For Business Customers
1. Access **Equipment Packages** for bulk equipment needs
2. Use **Bulk Discounts** calculator for multi-item savings
3. Apply **Promo Codes** for additional discounts
4. Track **Invoices** for accounting purposes

### For Admins/Owners
1. Use **Backend Portal** for comprehensive management
2. Check **Analytics Dashboard** for business insights
3. Send messages via **Communications Hub**
4. Schedule **Maintenance** to keep equipment operational

## Mobile Experience

On mobile devices:
- Header is streamlined with only essential buttons
- **Menu button** provides access to all features
- **Quick Actions Menu** is optimized for thumb reach
- Swipe gestures work in navigation menu
- Contact buttons (WhatsApp, Email, Phone) remain accessible

## Getting Help

If you can't find a feature:
1. Open **Feature Overview Dashboard** (Info button)
2. Use search/filter in **Navigation Menu**
3. Check **Quick Actions Menu** for common tasks
4. Contact support via **WhatsApp** button

## Feature Access Levels

| Access Level | Features Available |
|--------------|-------------------|
| **Guest** | Browse equipment, view reviews, contact information |
| **Authenticated User** | All customer features, rental history, loyalty program |
| **Business User** | All user features + bulk discounts, package deals |
| **Owner/Admin** | All features + analytics, communications, maintenance |

## Best Practices

1. **Explore Features** - Use Feature Overview Dashboard to learn about capabilities
2. **Organize Workflow** - Memorize Quick Actions for your most common tasks
3. **Check Notifications** - Enable relevant notification channels (Email/SMS/WhatsApp)
4. **Use Filters** - In Navigation Menu, focus on category relevant to your needs
5. **Mobile-First** - Platform is optimized for mobile, use it on the go
